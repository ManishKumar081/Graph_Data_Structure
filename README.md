# Graph Data Structure Repository

Welcome to the **Graph Data Structure Repository** 🚀

This repository is created for learning and practicing important concepts of **Graph Data Structures** along with frequently asked coding interview problems.

## 📌 What You Will Learn

* Graph Representation

  * Adjacency Matrix
  * Adjacency List

* Graph Traversal Algorithms

  * Breadth First Search (BFS)
  * Depth First Search (DFS)

* Shortest Path Algorithms

  * Dijkstra’s Algorithm
  * Bellman-Ford Algorithm
  * Floyd Warshall Algorithm

* Minimum Spanning Tree

  * Prim’s Algorithm
  * Kruskal’s Algorithm

* Topological Sorting

* Cycle Detection

  * Directed Graph
  * Undirected Graph

* Disjoint Set Union (DSU)

* Strongly Connected Components

* Bipartite Graph

* Bridges and Articulation Points

* Important Interview Problems

---

## 🎯 Purpose of this Repository

The main goal of this repository is to:

* Build strong understanding of graph concepts
* Practice coding interview problems
* Improve problem-solving skills
* Help students learn graph algorithms step by step
